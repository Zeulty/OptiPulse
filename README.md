# OptiPulse

**A Windows performance & gaming optimization tool.**

OptiPulse is a lightweight WPF desktop app for Windows that applies safe, tested system tweaks to reduce input latency, boost FPS, and clean up background clutter — all from a single, easy-to-use interface.

## Features

- **55+ system tweaks** across CPU/GPU, input, network, startup, and privacy — including Intel/AMD/NVIDIA GPU optimizations, keyboard & mouse buffer tuning, input latency removal, network latency optimization, and telemetry/bloatware removal.
- **One-click game packages** — apply a curated bundle of tweaks in one go:
  - 🎯 **Esports** — input-latency and UI responsiveness tweaks for competitive play
  - 🛡️ **Safe** — performance gains with zero risk, no security features touched
  - 🔥 **Overdrive** — aggressive, system-wide optimization for maximum performance
- **Risk-labeled tweaks** — every tweak is tagged by risk level so you always know what you're applying, with the option to revert.
- **System restore point** creation before risky changes, for peace of mind.
- **Real-time resource monitor** — live CPU, RAM, and disk usage at a glance.
- **Built-in scanner & cleaner** — find and remove junk files, temp data, and unnecessary background services.
- **Per-game optimizer** — apply targeted tweaks to a specific game's process.
- **Ghost Tools** — quick-access desktop context-menu shortcuts for instant memory purge and temp cleanup, no scripts needed.
- **Custom themes** — personalize the UI with adjustable accent colors.
- **Multi-language UI** — available in English, Turkish, Spanish, and Chinese.
- **Automatic update checks** via GitHub Releases.

## Installation

1. Download the latest installer from the [Releases](../../releases) page.
2. Run the installer and follow the setup wizard.
3. Launch OptiPulse and activate with your license key.

## Requirements

- Windows 10/11 (64-bit)
- .NET 8 Desktop Runtime (bundled with the installer)

## Usage

1. Open OptiPulse.
2. Pick a game package for instant optimization, or browse individual tweaks by category.
3. Review each tweak's risk level before applying.
4. (Optional) Create a restore point first if you're applying Overdrive-level tweaks.
5. Apply, and enjoy a snappier, cleaner system.

## Disclaimer

Some tweaks modify system-level settings (e.g. security mitigations, background services). Read each tweak's description and risk label before applying, and consider creating a system restore point beforehand.
